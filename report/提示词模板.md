# 提示词模板（通用，不含原片资产）

## A. 风格锁（全片复用）

```
电影感纪实短片，低饱和，冷灰偏暖一点的室内光，生活化家庭空间，
表演克制，无夸张表情，无卡通夸张变形，镜头稳定或极慢推，竖屏 9:16
```

按你的命题改最后一个逗号后的气质词即可；全片不要混写实/动漫。

## B. 角色锁（每个角色一张定版图后再写）

```
【图像1】为角色A（外形/发型/年龄感/服装以图为准，保持一致）
【图像2】为场景（以图为准）
第N镜，室内，中景：……具体动作一句……
限定：人物比例协调，发型服装与【图像1】一致，禁止换脸，禁止字幕烧录
```

## C. 复杂镜头拆分规则（来自公开创作者经验的迁移）

一次只让模型做一件难事：

- 先：手部与道具交互  
- 再：表情反应  
- 或拆成两个镜头，剪辑接上  

## D. 对比镜专用

```
同一机位、同一构图的前后对比：左侧/先前为较早年份家庭站位，
右侧/此刻为数年后面位；父亲身形更佝偻，母亲发色明显更浅；
光线与背景家具保持同一套参考，仅人物年龄特征变化
```
