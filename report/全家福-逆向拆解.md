## 3. 结构拆解（叙事 / 情绪工程）

### 3.1 一句话钩子

用**外来者的不懂**，把「子女缺席父母衰老」从习以为常变成可被看见的问题。

| 节拍 | 功能 | 观众情绪 |
|------|------|----------|
| 外星人带米面粮油上门采集影像 | 荒诞入口 + 善意感 | 好奇 |
| 拍照发现人数不对 / 儿子不在 | 缺口出现 | 不安 |
| 飞船接外地儿子回家 | 科幻解决「物理距离」 | 短暂希望 |

| 文案落点：缺席了慢慢变老的那些年 | 命题回收 | 余韵 / 共鸣 |

### 3.3 提示词与表达套路（推断，标清）

公开材料**没有**放出逐镜提示词。可从作者自述与成片反馈反推「套路」，仅作复刻指导：

- **命题先行**：先有「缺席×衰老」命题，再包一层荒诞外壳（外星人）。
- **外壳克制**：外星人系列「低饱和冷灰、表演不夸张」——奇观服务于议题，不抢戏。
- **关键对比可量化**：身高厘米、白发——比纯煽情旁白更易传播截图。
- **结尾克制**：作者明确不想落成简单「常回家看看」口号，而强调「被跳过的日常真实存在」。

任选其一，保持「外来观察者 / 量化对比 / 克制结尾」三件套即可验证结构是否成立。
